# 📱 Оптимизатор телефона

Android-приложение для ускорения и очистки телефона. Kotlin + Jetpack Compose, Material 3, интерфейс на русском.

## Возможности

| Раздел | Что делает |
|---|---|
| 🏠 **Главная** | Индекс здоровья телефона (0–100) по ОЗУ, памяти и батарее. Кнопка «Быстрая оптимизация» — ускорение + удаление безопасного мусора. |
| 🧹 **Очистка** | Ищет временные файлы (`.tmp`, `.log`, `.bak`…), миниатюры, пустые папки, старые APK и файлы больше 100 МБ. Выбор по категориям или по отдельным файлам, подтверждение перед удалением. |
| 🚀 **Ускорение** | Закрывает фоновые процессы пользовательских приложений и показывает, сколько ОЗУ освободилось. Память обновляется в реальном времени. |
| 🔋 **Батарея** | Заряд, температура, напряжение, состояние, технология — с живым обновлением. Советы по экономии и быстрые ссылки на энергосбережение. |
| 📦 **Приложения** | Размер и кэш каждого приложения, сколько дней не открывалось. Фильтры «Не используются» (30+ дней) и «Большой кэш». Удаление и переход к очистке кэша в один тап. |

## Разрешения

- **Доступ ко всем файлам** — для поиска мусора по всей памяти (запрашивается в разделе «Очистка»).
- **Доступ к статистике использования** — для размеров приложений и даты последнего запуска («Приложения»).
- Остановка фоновых процессов и список приложений — выдаются автоматически.

Приложение ничего не отправляет в интернет (разрешения `INTERNET` нет).

## Сборка

Требуется Android SDK (API 35) и JDK 17.

```bash
./gradlew assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```

Готовый APK собирается автоматически в GitHub Actions при каждом push — ищите его во вкладке **Actions → Build APK → Artifacts**.

Минимальная версия Android — 8.0 (API 26).

## Честно о возможностях

Начиная с Android 6, обычное приложение не может очищать кэш *других* приложений, а Android 11+ закрывает доступ к `Android/data`. Поэтому для чужого кэша оптимизатор открывает системную страницу приложения, где кэш чистится одной кнопкой. Ускорение ОЗУ закрывает только фоновые процессы — эффект зависит от прошивки.
